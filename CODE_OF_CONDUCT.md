# Código de conducta

Este proyecto adopta el
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Se espera una comunidad abierta, respetuosa y libre de acoso. Para reportar
conducta inaceptable, contactá al mantenedor mediante un canal privado de su
perfil de GitHub. Los reportes se revisarán de forma confidencial y se aplicarán
medidas proporcionales, incluida la moderación o exclusión del proyecto.
